中英文放在一起，像两种不同的声音。一个方正、紧凑，一个舒展、轻重分明。好的混排，不是让它们变得一样，而是让它们彼此听见。

> 本文是本站的排版试样。下面的标题、引文、列表、代码、表格与注脚，供检查阅读效果使用。

## 字体是一种语气

中文使用京华老宋体，英文使用 IM Fell English。前者带着旧印刷品的痕迹，后者的字形像一本被翻过许多遍的小书。

字体栈里，拉丁字体放在前面。遇到它不认识的汉字，浏览器才向后寻找中文字体。[^fonts]

<span lang="en">A page is a place to pause. Between the lines, a little room for thought.</span>

## 引文与强调

> 排版的任务，不是让读者看见设计，而是让读者看见文字。

这里有一段**需要强调的文字**，也有一个指向[文章归档](/site/blog/)的链接。强调不必总是更粗；一条细线也可以把注意力轻轻留下。

### 几个小约定

1. 中文使用全角标点，例如逗号、句号与「引号」。
2. 日期统一写作 2026-10-01，避免标签里的字形来回跳动。
3. 一段话不宜太宽，让视线轻松找到下一行。

## 代码也是文字

行内代码如 `font-display: swap`，应该清楚，但不抢眼。

```css
:root {
  --paper: #f4ecd8;
  --ink: #2b2118;
  --font-body: "IM Fell English", "KingHwaOldSong", "Songti SC", serif;
}

/* 中文正文：多留一点行间的呼吸 */
.prose {
  line-height: 1.8;
  text-align: justify;
}
```

## 一张小表格

| 用途 | 字体 | 细节 |
| --- | --- | --- |
| 中文正文 | 京华老宋体 | 系统宋体作为兜底 |
| English | IM Fell English | 本地托管，按需加载 |
| 日期与标签 | Special Elite | 数字日期，打字机质感 |
| 代码 | TT2020 Style E | 轻微磨损的等宽打字机字体，横向滚动 |

表格和代码在窄屏上各自滚动，不把整张页面撑宽。暗色模式下，纸张变成灯下的深褐色，文字仍然清晰。
